## Git Workflow

**Commit and push frequently throughout every work session.** The goal is that GitHub always reflects the current state of work — never let meaningful progress exist only locally.

- Commit after every logical unit of work (new file, feature complete, bug fixed, config changed)
- Push immediately after each commit — do not batch pushes
- Use clean, descriptive commit messages in imperative mood (e.g. "Add user authentication", "Fix message parsing bug")
- Never end a session or task without committing and pushing all changes
