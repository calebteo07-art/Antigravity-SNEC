## Project

SNEC_AI_CHATBOT — an AI chatbot project. This repository is in early setup; architecture and tooling will be documented here as the project develops.

## Git Workflow

All changes should be committed locally and pushed to `https://github.com/calebteo07-art/SNEC_AI_CHATBOT.git`.

- Use clean, descriptive commit messages (imperative mood, e.g. "Add user authentication")
- Push after every meaningful set of changes so GitHub always has a current backup
- Branch is `main`
